# 工作任务优先级排序功能开发计划

## 需求概述

在主模组的任务切换界面中，实现一个任务优先级排序系统：

1. **双列布局**：左列显示未排序任务，右列显示已排序任务（含优先级数字）
2. **优先级数字**：通过 1-10 设置优先级，数字越小优先级越高
3. **点击标签启用**：点击任务标签启用排序，标签旁显示优先级数字
4. **同优先级排序**：同优先级内按任务标签顺序排序（可调节）
5. **AI 配置**：通过 ITool 让 AI 可以配置优先级
6. **配置文件**：已设定的排序可保存、切换、命名


**配置文件位置**：`config/tlm_sincerely/task_priority_presets.json`

### 2. GUI 实现

**方式**：使用 Mixin 在女仆界面的侧边栏（MaidSideTabs）中添加新按钮，点击直接打开客户端独立 Screen

**入口**：在侧边栏 `TASK_BOOK`(index=0)、`GLOBAL_CONFIG`(index=1) 按钮下方添加第三个按钮 `priority`(index=2)

**关键变更**：侧边栏按钮不走 ToggleTabMessage 网络流程，直接客户端打开 Screen
- 不需要服务端 Container/MenuType
- 不需要 EntityMaidGuiMixin
- 不需要 PriorityRegistry

**Mixin 目标**：

| 目标类 | 方法 | 注入点 | 功能 |
|--------|------|--------|------|
| `MaidSideTabs` | `getTabs()` | `@At("RETURN")` | 在返回数组中追加优先级侧边栏按钮 |

**客户端流程**：
```
用户点击侧边栏优先级按钮
  → MaidSideTabButton.onClick()
  → TaskPriorityScreen.open(maid)
  → 打开独立优先级配置界面
```

**优先级配置界面布局**（独立 Screen，不复用 Container 系统）：

**实现要点**：
- Mixin `MaidSideTabs.getTabs()` 使用反射读取私有字段（entityId, rightPos, topPos）
- 按钮使用 `MaidSideTabButton` 组件，索引=2（`SPACING * 2`），key 为 `"task_priority"`
- 点击直接 `Minecraft.setScreen(new TaskPriorityScreen(maid))`
- 任务列表使用主模组的 `TaskButton` 样式或自定义仿制样式
- 优先级数字按钮支持鼠标滚轮调节（`mouseScrolled`）

### 3. 自动切换逻辑

**实现方式**：条件触发式自动切换

**切换规则**：
- 每 20 tick（1秒）检查一次条件变化
- 遍历优先级列表（从高到低），找到第一个满足启用条件的任务
- 如果该任务优先级高于当前任务，自动切换
- 切换后设置冷却时间（防止频繁切换，默认 100 tick = 5秒）

**条件检查示例**：
```java
// 检查任务是否满足启用条件
public boolean isTaskAvailable(EntityMaid maid, IMaidTask task) {
    // 使用主模组已有的 isEnable() 方法
    return task.isEnable(maid);
}

// 选择最高优先级的可用任务
public IMaidTask selectHighestPriorityTask(EntityMaid maid) {
    for (Map.Entry<ResourceLocation, Integer> entry : sortedPriorities) {
        IMaidTask task = TaskManager.findTask(entry.getKey()).orElse(null);
        if (task != null && isTaskAvailable(maid, task)) {
            return task;
        }
    }
    return TaskManager.getIdleTask(); // 无可用任务时切换到待命
}
```

**实现要点**：
- 在服务端 Tick 事件中检查
- 只在女仆处于工作模式（WORK Activity）时触发
- 与主模组的 `IMaidTask.isEnable()` 方法集成

## 风险与注意事项

1. **Mixin compatibilityLevel**：本项目使用 Mixin 0.8.5，`compatibilityLevel` 必须设为 `JAVA_8`（不能写 `JAVA_17`，否则 Mixin 类不会加载）
2. **Mixin remap = false**：注入主模组自定义方法时必须加 `remap = false`，否则编译失败
3. **MaidSideTabs.getTabs 返回数组**：Mixin `@At("RETURN")` 通过反射读取私有字段后创建新数组替换返回值
4. **侧边栏索引**：SideTab 枚举只有 0/1 两个值，新按钮使用索引=2（SPACING*2=50），需手动计算纹理坐标
5. **独立 Screen**：不依赖 Container 系统，无物品栏槽位，纯配置界面
6. **性能**：自动切换逻辑不宜过于频繁，建议每 20 tick 检查一次
7. **兼容性**：确保与主模组的任务切换机制不冲突
8. **数据持久化**：JSON 配置文件需要处理好并发读写
