# 时间段工作安排（Schedule Mode）

## 概述

新增"时间段模式"作为探针模式的替代方案。玩家为每个预设配置时间段→任务映射，女仆按游戏内时间自动切换。时间段可跨越午夜，每日循环。

## 设计决策

- **时间基准**：游戏内时间（`level.getDayTime() % 24000`，0-24000 对应一天）
- **模式关系**：与探针完全独立，通过配置 `SwitchMode` 二选一
- **跨午夜**：每日循环。如 `start=20000 end=6000` 表示每晚 20:00 到次日 06:00
- **无匹配时**：保持当前任务不变

## 时间段匹配逻辑

```java
public static boolean inSlot(long gameTime, ScheduleSlot slot) {
    int time = (int)(gameTime % 24000);
    if (slot.startTick < slot.endTick) {
        // 正常区间：06:00-18:00
        return time >= slot.startTick && time < slot.endTick;
    } else {
        // 跨午夜：20:00-06:00
        return time >= slot.startTick || time < slot.endTick;
    }
}
```

遍历 schedule 列表，返回第一个匹配的 slot。无匹配 → 返回 null → 保持当前任务。

## Handler 逻辑

`TaskAutoSwitchHandler.onServerTick()` 入口分流：

```
if SwitchMode == PROBE:
    → 现有探针逻辑（不变）
else if SwitchMode == SCHEDULE:
    → 每 CHECK_INTERVAL tick：
        gameTime = level.getDayTime() % 24000
        matchingSlot = findMatchingSlot(gameTime, schedule)
        if matchingSlot != null:
            targetTask = TaskManager.findTask(matchingSlot.taskId)
            if targetTask != null && targetTask != currentTask:
                if targetTask.isEnable(maid):
                    maid.setTask(targetTask)
                    cooldowns.put(maidId, currentTick)
```

**极简**——无 brain 状态检测、无探针、无宽限期、无冷却（除了 PollInterval 防抖）。

## 验证

1. 配置 SwitchMode=SCHEDULE + 时间段：女仆在对应时间自动切换 ✓
2. 跨午夜 slot（20:00-06:00）：晚 22:00 匹配、凌晨 03:00 匹配、中午 12:00 不匹配 ✓
3. 无匹配时间段：女仆保持当前任务不变 ✓
4. SwitchMode=PROBE：行为与之前完全一致 ✓
5. isEnable()=false 的任务：跳过，不切换 ✓
