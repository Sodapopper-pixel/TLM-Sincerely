# 预设人格系统

## 需求概述

为女仆提供全局预设人格（角色提示词）管理功能。玩家创建/编辑人格模板，每只女仆独立选择激活的人格，选中的人格提示词自动注入 AI 对话上下文以影响女仆的说话风格和行为。

---

### 数据流

```
创建/编辑人格流程：
  玩家点击侧边栏按钮 → PersonalityScreen(maid)
  → 左侧一览人格列表，右侧编辑选中人格的提示词
  → 修改自动保存至 PersonalityManager → JSON

女仆选择人格流程：
  玩家在 PersonalityScreen 中点击某人格的 [使用] 按钮
  → 写入 maid.getPersistentData().putString("tlm_sincerely_personality", name)

AI 对话注入流程：
  玩家与女仆对话 → 主模组拼装 Context
  → PersonalityContext.getValue(maid)
  → 读取 maid NBT 中的人格名
  → PersonalityManager.getPreset(name).getPrompt()
  → 返回提示词文本，自动注入到 <context> 块
```

## 数据模型

### PersonalityPreset.java

```java
// package: com.github.tartaricacid.tlm_sincerely.personality
public class PersonalityPreset {
    private String name;    // 人格名称，全局唯一（如 "温柔"、"傲娇"）
    private String prompt;  // 提示词正文，注入给模型的角色扮演指引
}
```

### PersonalityManager.java

```java
// package: com.github.tartaricacid.tlm_sincerely.personality
// 全局人格预设管理器（JSON 持久化）

静态方法:
  loadPresets()                   // 懒加载，首次调用自动读取 JSON
  savePresets()                   // 每次修改后立即写入文件
  getPreset(String name)          // 获取指定名称的预设
  getPresetNames()                // 获取所有预设名称列表
  getPresets()                    // 获取所有预设
  addPreset(PersonalityPreset)    // 添加预设（重名跳过）
  removePreset(String name)       // 删除预设（至少保留一个）
  renamePreset(String old, String new) // 重命名
```

### JSON 文件格式

```json
{
    "presets": [
        {
            "name": "温柔",
            "prompt": "你是一个温柔体贴的女仆，说话语气柔和..."
        },
        {
            "name": "傲娇",
            "prompt": "你是一个傲娇的女仆，口是心非..."
        }
    ]
}
```

文件路径：`config/tlm_sincerely/personality_presets.json`

### 女仆 NBT 数据

每只女仆通过 `getPersistentData()` 存储当前选择的人格名：

```
键: "tlm_sincerely_personality"
值: "温柔"（String）
```

无数据或空字符串 = 未选择人格 = 默认行为。

## 详细设计

### 1. PersonalityPreset.java

```java
package: com.github.tartaricacid.tlm_sincerely.personality

public class PersonalityPreset:
    private String name      // 人格名称，不可为空
    private String prompt    // 提示词文本，不可为空

    // 构造
    PersonalityPreset(String name, String prompt)
    PersonalityPreset(String name)  // prompt = ""

    // getter/setter
    getName() / setName(String)
    getPrompt() / setPrompt(String)
```

极简数据类，无复杂逻辑。

### 2. PersonalityManager.java

完全仿照 `TaskPriorityManager` 的结构：

```java
package: com.github.tartaricacid.tlm_sincerely.personality

public final class PersonalityManager:
    static Gson GSON = new GsonBuilder().setPrettyPrinting().create()
    static Path CONFIG_DIR = FMLPaths.CONFIGDIR.get().resolve("tlm_sincerely")
    static String FILE_NAME = "personality_presets.json"
    static Map<String, PersonalityPreset> presets = LinkedHashMap<>()
    static boolean loaded = false

    loadPresets(): 同 TaskPriorityManager 模式
        - 首次调用创建默认预设（"默认"人格，空提示词）
        - 读取 JSON → 反序列化到 presets map

    savePresets():
        - 序列化 presets → JSON → 写入文件

    getPresetNames(): 返回 presets.keySet() 列表
    getPreset(String): 根据名称取
    getPresets(): 返回 presets.values() 集合
    addPreset(PersonalityPreset): put 到 map + save
    removePreset(String): remove（至少保留一个）+ save
    renamePreset(String, String): remove + put + save
```

JSON 序列化格式：
```json
{
    "presets": [
        {"name": "温柔", "prompt": "你是一个温柔..."},
        {"name": "傲娇", "prompt": "你是一个傲娇..."}
    ]
}
```

### 3. PersonalityContext.java

```java
package: com.github.tartaricacid.tlm_sincerely.ai.context

public class PersonalityContext extends AbstractMaidContext {
    public PersonalityContext() {
        super("tlm_sincerely_personality", "Maid personality");
    }

    @Override
    public String getValue(EntityMaid maid) {
        String name = maid.getPersistentData().getString("tlm_sincerely_personality");
        if (name.isEmpty()) return "None";
        PersonalityManager.loadPresets();
        PersonalityPreset preset = PersonalityManager.getPreset(name);
        return preset != null ? preset.getPrompt() : "None";
    }
}
```

注册方式（SincerelyExtension）：
```java
@Override
public void registerAIMaidContext(GameContextRegister register) {
    register.registerCategory("tlm_sincerely_personality",
        "Maid personality and character prompt", true);
    register.registerContext("tlm_sincerely_personality", new PersonalityContext());
}
```

> `promptContext = true`：人格提示词在每轮对话中自动注入，确保角色一致性。

### 4. PersonalityTool.java

Tool ID: `tlm_personality`

```java
package: com.github.tartaricacid.tlm_sincerely.ai.tool

public class PersonalityTool implements ITool<PersonalityTool.Result>:
    TOOL_ID = "tlm_personality"
    TOOL_DESC = """
        Query or change the maid's current personality/character setting.
        Use 'current' to see the active personality.
        Use 'available' to list all personality presets.
        Use 'set' to switch the maid's personality.
        """
    CODEC = RecordCodecBuilder: action, personality_name

    parameters(ObjectParameter root, EntityMaid maid):
        - action: StringParameter, enum=["current", "available", "set"], required
        - personality_name: StringParameter, 枚举所有预设名, required=false

    onCall(toolCallId, result, callback):
        - current: 返回当前女仆 NBT 中的人格名 + 完整提示词
        - available: 返回所有预设名称列表
        - set: 校验名称存在 → 写入 maid NBT → 返回确认

    record Result(String action, String personalityName)
```

**布局说明**：
- 背景纹理：新建 `textures/gui/personality_gui_bg.png`（或复用 priority_gui_bg.png）

- 右侧编辑器内容变化 → 实时写入 PersonalityManager + savePresets()

**简化版方案**（如 MultiLineEditBox 不可用）：
- 右侧用普通单行 `EditBox` 替代
- 或实现一个简易多行文本输入组件

## 与主模组的兼容性

| 对接点 | 兼容性 |
|--------|--------|
| `registerAIMaidContext` — `tlm_sincerely_personality` 分类 | ✅ 独立分类，不与内置 status/world 等冲突 |
| `promptContext=true` — 自动注入提示词 | ✅ 主模组将所有 promptContext=true 的分类拼入 `<context>` 块 |
| `registerAITool` — `tlm_personality` | ✅ 按 ID 去重，不与 query_game_context 等冲突 |
| 女仆 NBT — `tlm_sincerely_personality` 键 | ✅ 使用 `getPersistentData()`，保存女仆时自动持久化 |
| Mixin — `MaidSideTabs.getTabs()` | ✅ 与现有 Priority 按钮共享同一注入点，追加 index=3 |

## 已知限制

- 提示词文本在每轮对话中自动注入，长提示词会增加 token 消耗
- 无分类/标签机制（如"战斗人格""社交人格"），后续可扩展
- 无 AI 自动检测语境选择人格（如战斗时切换战斗人格）
- 侧边栏按钮纹理需要手动制作 16×16 图标
- 女仆死亡/消失后人格数据跟随 NBT，重生后保留
