# 预设人格系统

## 需求概述

为女仆提供全局预设人格（角色提示词）管理功能。玩家创建/编辑人格模板，将预设提示词**写入主模组的 `customSetting` 字段**。主模组已将该字段作为 LLM 的 SYSTEM 消息注入，无需额外处理 AI 上下文注入。

**核心交互**：玩家手动切换、配置人格，AI 不参与人格切换（保持角色一致性）。

### 数据流

```
创建/编辑人格流程：
  玩家打开 PersonalityScreen → 新建/选择人格 → 编辑提示词
  → 实时写入 PersonalityManager → JSON

应用人格到女仆流程：
  玩家在 PersonalityScreen 点击 [应用]
  → maid.getAiChatManager().customSetting = preset.getPrompt()
  → PacketDistributor.sendToServer(new SaveMaidAIDataPackage(...))
  → 主模组自动在下次对话时使用新的 SYSTEM prompt

从女仆导入人格流程：
  玩家在 PersonalityScreen 点击 [从当前导入]
  → 读取 maid.getAiChatManager().customSetting
  → 创建新预设 / 覆盖当前选中预设

AI 对话注入流程（主模组已有，无需本 mod 干预）：
  玩家与女仆对话 → MaidAIChatManager.getMessages()
  → 检测 customSetting 非空 → PapiReplacer.replaceSetting()
  → LLMMessage.systemChat(maid, setting) → 作为首条 SYSTEM 消息
```

## 数据模型

### PersonalityPreset.java

```java
// package: com.github.tartaricacid.tlm_sincerely.personality
public class PersonalityPreset {
    private String name;    // 人格名称，全局唯一（如 "温柔"、"傲娇"）
    private String prompt;  // 提示词正文，即直接写入 customSetting 的角色扮演指引
}
```

### PersonalityManager.java

仿照 `TaskPriorityManager` 的结构，管理全局预设模板库：

```java
// package: com.github.tartaricacid.tlm_sincerely.personality
// JSON 文件: config/tlm_sincerely/personality_presets.json

静态方法:
  loadPresets()                   // 懒加载，首次调用自动读取 JSON
  savePresets()                   // 每次修改后立即写入文件
  getPreset(String name)          // 获取指定名称的预设
  getPresetNames()                // 获取所有预设名称列表
  addPreset(PersonalityPreset)    // 添加预设（重名跳过）
  removePreset(String name)       // 删除预设（至少保留一个）
  renamePreset(String old, String new) // 重命名
```

### JSON 文件格式

```json
{
    "presets": [
        {
            "name": "温柔",
            "prompt": "你是一个温柔体贴的女仆，说话语气柔和..."
        },
        {
            "name": "傲娇",
            "prompt": "你是一个傲娇的女仆，口是心非..."
        }
    ]
}
```

文件路径：`config/tlm_sincerely/personality_presets.json`

### 女仆数据存储

**不新增 NBT 键**。预设仅作为模板库存储在 JSON 中，应用到女仆时直接写入主模组已有的 `MaidAIChatSerializable.customSetting` 字段（该字段已随女仆实体持久化到 NBT `MaidAIChat.CustomSetting`，并通过 `SaveMaidAIDataPackage` 网络包同步）。

```
maid.getAiChatManager().customSetting  ← 写入预设的 prompt 文本
```

## 详细设计

### 1. PersonalityPreset.java

```java
package: com.github.tartaricacid.tlm_sincerely.personality

public class PersonalityPreset:
    private String name      // 人格名称，不可为空
    private String prompt    // 提示词文本

    // 构造
    PersonalityPreset(String name, String prompt)
    PersonalityPreset(String name)  // prompt = ""

    // getter/setter
    getName() / setName(String)
    getPrompt() / setPrompt(String)
```

### 2. PersonalityManager.java

完全仿照 `TaskPriorityManager` 的 JSON CRUD 模式：

```java
package: com.github.tartaricacid.tlm_sincerely.personality

public final class PersonalityManager:
    static Gson GSON = new GsonBuilder().setPrettyPrinting().create()
    static Path CONFIG_DIR = FMLPaths.CONFIGDIR.get().resolve("tlm_sincerely")
    static String FILE_NAME = "personality_presets.json"
    static Map<String, PersonalityPreset> presets = LinkedHashMap<>()
    static boolean loaded = false

    loadPresets():
        - 读取 JSON → 反序列化到 presets map
        - 首次调用无文件时创建默认预设（"默认"人格，含基础提示词）

    savePresets():
        - 序列化 presets → JSON → 写入文件

    getPresetNames(): 返回 presets.keySet() 列表
    getPreset(String): 根据名称取
    addPreset(PersonalityPreset): put 到 map + save
    removePreset(String): remove（至少保留一个）+ save
    renamePreset(String, String): remove + put + save
```

### 3. PersonalityScreen.java (GUI)

```
┌─────────────────── 256×256 ───────────────────┐
│  当前女仆人格：[温柔]  [←] [→]                  │  ← 顶部导航行
│                                      [新建] [删除]  │  ← 操作行
│                                                  │
│  ┌── 人格预设库 ────┐┃┌── 提示词编辑 ──────────┐ │
│  │ ▸ 温柔 (当前)    │┃│                         │ │
│  │   傲娇           │┃│  (MultiLineEditBox)     │ │
│  │   元气           │┃│  你是一个温柔体贴的      │ │
│  │   三无           │┃│  女仆，说话语气柔和。    │ │
│  │   病娇           │┃│  对主人始终保持敬语，    │ │
│  │                  │┃│  遇到危险时优先保护主人  │ │
│  │                  │┃│  ...                    │ │
│  │                  │┃│                         │ │
│  │                  │┃│                         │ │
│  │   ◀         ▶    │┃│  [保存]  [应用]  [导入] │ │
│  └──────────────────┘┃└─────────────────────────┘ │
│              (分隔线 x=100)                       │
└──────────────────────────────────────────────────┘
```

**布局参数**：
- 背景：`textures/gui/personality_gui_bg.png`（256×256，或复用 `priority_gui_bg.png`）
- 左列 x=7, w=93（人格预设列表 + 翻页按钮）
- 分隔线 x=100
- 右列 x=107, w=142（提示词编辑区）
- 每行高度 16px，左列最多显示 10 行

**控件说明**：
- 顶部行：[当前女仆人格] 显示标签 — 从 `customSetting` 内容前 20 字符截断推测名称，或匹配预设库中的名称
- 顶部行：[←][→] 快速切换预设（循环）
- 操作行：[新建] — 弹出命名输入 → 创建空白人格
- 操作行：[删除] — 确认 → 删除当前选中人格（至少保留一个）
- 左列：人格名称列表按钮，`▸` 标记当前选中（编辑中），高亮标记当前女仆使用的人格
- 右列：`EditBox` 单行文本编辑器（Minecraft 1.20.1 Forge 无 `MultiLineEditBox`，暂用长单行替代，`setMaxLength(4096)`）
- 底行：[保存] — 将右侧编辑内容写入当前选中预设（实时保存则省略）
- 底行：[应用] — 将当前选中预设的 prompt 写入 `maid.getAiChatManager().customSetting`，发送 `SaveMaidAIDataPackage`
- 底行：[导入] — 从 `maid.getAiChatManager().customSetting` 读取当前文本，创建新预设

**关键行为**：
- 点击左列人格名称 → 右侧编辑器加载 prompt 文本 → 标记为选中编辑中
- [新建] → 输入名称 → 创建空白人格
- [删除] → 删除当前选中人格（至少保留一个）
- [应用] → `customSetting = preset.getPrompt()` → 发送网络包
- [导入] → 读取当前女仆 `customSetting`，若非空则创建为预设（命名：当前人格名_导入）
- 右侧编辑器失去焦点或内容变化 → 自动保存到 PersonalityManager + JSON（实时保存风格）

### 6. SettingEditMixin.java（可选扩展）

在 `SettingEditScreen` 界面注入「预设库」按钮，方便用户从主模组提示词编辑界面直接打开预设管理器。注入点在 `init()` 方法末尾（`@Inject @At("TAIL")`, `remap = false`）：

```java
@Mixin(SettingEditScreen.class)
public class SettingEditMixin {
    @Inject(method = "init", at = @At("TAIL"), remap = false)
    private void tlmSincerely$addPresetButton(CallbackInfo ci) {
        SettingEditScreen self = (SettingEditScreen) (Object) this;
        // 在保存按钮附近添加"预设库"按钮
        // 通过反射读取 self.maid 字段
        // 按钮点击 → Minecraft.setScreen(new PersonalityScreen(maid))
    }
}
```

> **注意**：`SettingEditScreen` 字段均为 private，需要通过反射读取 `maid` 字段。如果反射复杂度过高，此 Mixin 可延后实施，侧边栏按钮已提供主入口。

### 8. SincerelyExtension.java 修改

仅追加配置注册，无需修改 AI Tool/Context 注册：

```java
public SincerelyExtension() {
    MinecraftForge.EVENT_BUS.register(this);
    if (!configRegistered) {
        configRegistered = true;
        // 需要将 builder 传递给 PersonalityConfig.init()
        // 当前 init() 直接 build 返回，需改为先创建 builder 再各 subconfig init
        ModLoadingContext.get().registerConfig(ModConfig.Type.COMMON, GeneralConfig.init());
        ConfigScreen.register();
    }
}
```

**注意**：`GeneralConfig.init()` 已在内部调用了 `ChatBarConfig.init(builder)` 和 `PriorityConfig.init(builder)`，只需追加 `PersonalityConfig.init(builder)` 即可，无需重构构造函数。

## 与主模组的兼容性

| 对接点 | 兼容性 |
|--------|--------|
| `maid.getAiChatManager().customSetting` | ✅ 公开字段，主模组 `SettingEditScreen` 也在用 |
| `SaveMaidAIDataPackage` 网络包 | ✅ 主模组已定义，直接复用 |
| `MaidAIChatManager.getMessages()` | ✅ 主模组自动读取 `customSetting` 作为 SYSTEM 消息，无需本 mod 干预 |
| Mixin — `MaidSideTabs.getTabs()` | ✅ 与现有 Priority 按钮共享同一注入点，追加 index=3 |
| Mixin — `SettingEditScreen.init()` | ⚠️ 需要反射读取 private `maid` 字段，可选实施 |
| 无新增 AI Context/Tool | ✅ 不影响主模组内置 context/tool 注册 |

## 已知限制

- 提示词文本作为 SYSTEM 消息注入，长提示词增加 token 消耗
- 右侧编辑器暂用单行 `EditBox`（Minecraft 1.20.1 无 `MultiLineEditBox`），编辑体验有限
- 无预设分类/标签机制（如"战斗人格""社交人格"），后续可扩展
- `SettingEditScreen` Mixin 依赖反射，主模组重构 `maid` 字段名会失效
- 侧边栏按钮纹理需手动制作 16×16 图标
